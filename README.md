# lab4_graphics

## Инструкция по сборке и запуску
Подготовить проект после того, как открыли репозиторий в Visual Studio 2022 (через `Open with Visual Studio`)

### 1. Откройте командную строку разработчика
В меню **Инструменты** → **Командная строка** → **Командная строка разработчика для VS 2022** (Developer Command Prompt for VS 2022).  
Убедитесь, что текущим каталогом является корень проекта (там, где лежит `lab4_graphics.sln`).

### 2. Установите и интегрируйте пакет vcpkg (если ещё не установлен)
В командной строке выполните:

```bash
git clone https://github.com/microsoft/vcpkg.git
cd vcpkg
.\bootstrap-vcpkg.bat
cd ..
.\vcpkg\vcpkg integrate install
```

### 3. Откройте решение и соберите проект
Закройте командную строку и вернитесь в Visual Studio.
Откройте файл решения lab4_graphics.sln (если он ещё не открыт).
В меню выберите Сборка → Собрать решение (или нажмите Ctrl+Shift+B).
Все необходимые библиотеки (GLFW, GLAD, GLM, stb) будут автоматически загружены и настроены через vcpkg.
